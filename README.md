# SalesIQ Copilot

Projeto de demonstração com backend em Python e frontend em Next.js para análise de mercado e atendimento ao cliente.

## Estrutura

- `backend/` - API Python com rotas, configuração e serviços de ML.
- `frontend/` - Aplicação Next.js com interface de usuário e componentes para visualização de dados.
- `knowledge/` - Regras de métricas de mercado e contexto de vendas.

## Como executar

### Backend

1. Navegue até `backend/`
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python run.py`

### Frontend

1. Navegue até `frontend/`
2. Instale as dependências: `npm install`
3. Execute: `npm run dev`

## Observações

- Ajuste variáveis de ambiente conforme necessário para chaves de API ou configurações locais.
- Este repositório é adequado para desenvolvimento local e teste de integração entre frontend e backend.
